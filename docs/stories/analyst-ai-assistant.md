# Story: AI-ассистент для аналитика

## User story

**Как аналитик,** я хочу использовать AI-ассистента для исследования данных, подготовки требований и оформления результатов, **чтобы** быстрее получать обоснованные выводы и уделять больше времени проверке гипотез и принятию решений.

## Критерии приёмки

- Аналитик может описать задачу, а ассистент помогает уточнить цель, ожидаемый результат и составить план работы.
- Ассистент помогает сформулировать гипотезы, метрики, критерии успеха и вопросы для исследования.
- По предоставленной схеме данных ассистент может предложить SQL-запросы, формулы или код для анализа.
- По предоставленным результатам ассистент помогает выявить закономерности и сформулировать выводы, отделяя наблюдения от предположений.
- В ответе обозначены ограничения анализа, допущения и необходимые проверки.
- Аналитик может попросить оформить результат как краткое резюме, отчёт или тезисы для презентации.
- Аналитик проверяет исходные данные и выводы перед использованием; конфиденциальные данные не передаются без разрешения.

## Задачи аналитика с помощью ассистента

### 1. Уточнить и спланировать работу

- Сформулировать цель и ожидаемый результат аналитической задачи.
- Подготовить вопросы для заказчика и выявить недостающие вводные.
- Разбить работу на этапы, обозначить зависи��ости и риски.

### 2. Подготовить исследование

- Сформулировать проверяемые гипотезы.
- Подобрать метрики и критерии успеха.
- Составить план анализа и определить необходимые данные.

### 3. Подготовить работу с данными

- Разобрать предоставленную схему таблиц и полей.
- Написать или проверить SQL-запросы, формулы и код анализа.
- Предложить проверки качества данных и варианты их очистки.
- Найти возможные тенденции, выбросы и изменения в предоставленных результатах.

### 4. Интерпретировать результаты

- Сформулировать выводы на основе предоставленных данных.
- Отделить подтверждённые наблюдения от гипотез и предположений.
- Указать ограничения, возможные смещения и вопросы для дополнительной проверки.
- Предложить следующие ��налитические шаги.

### 5. Оформить результаты

- Подготовить краткое резюме для руководителя или заказчика.
- Структурировать аналитический отчёт.
- Составить тезисы для презентации или обсуждения.
- Переписать выводы ясным и кратким языком для выбранной аудитории.

### 6. Поддерживать документацию

- Описать метрики, определения и правила расчёта.
- Подготовить черновик требований к отчёту или дашборду.
- Зафиксировать допущения, источники данных и принятые решения.

## Ограничения и ответственность

Ассистент помогает ускорить аналитическую работу, но не заменяет проверку данных и экспертную оценку. Аналитик отвечает за подтверждение результатов и выводов перед их использованием.
