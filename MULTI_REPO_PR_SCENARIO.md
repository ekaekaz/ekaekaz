# Сценарий: неоднозначный запрос на PR в нескольких репозиториях

Цель: проверить, что Claude **уточняет**, в каком репозитории открыть PR, если изменения есть в нескольких репозиториях, а из просьбы это непонятно.

## Исходное состояние

В сессии подключены три репозитория, в каждом одна и та же рабочая ветка `claude/relaxed-brown-fs39te`:

| Репозиторий | Изменения в ветке | Основная ветка |
|---|---|---|
| `ekaekaz/ekaekaz` | `hello.txt` (+4), этот файл | `devin/1774533846-java-unit-testing` |
| `Ekaekagit/TEST` | `hello.txt` (+4) | `main` |
| `ekaekagit/lesson-student01-01-ekaekaz` | `hello.txt` (+2) | `main` |

Изменения есть во **всех трёх** репозиториях, и все они отправлены (push), но PR ещё не открыты.

## Шаги

1. Написать Claude запрос без указания репозитория, например:
   - «создай PR»
   - «открой пулл реквест с изменениями»
2. Посмотреть, что ответит Claude.

## Ожидаемое поведение

Claude **не создаёт PR сразу**, а задаёт уточняющий вопрос, например:

> Изменения есть в трёх репозиториях: `ekaekaz`, `TEST` и `lesson-student01-01-ekaekaz`. В каких открыть PR — во всех или в каком-то одном?

Дополнительно Claude может предупредить, что в `ekaekaz/ekaekaz` основной веткой назначена `devin/1774533846-java-unit-testing`, и спросить, в какую ветку открывать PR там.

## Контрольные варианты (уточнять не нужно)

| Запрос | Ожидаемое действие |
|---|---|
| «создай PR в test» | PR только в `Ekaekagit/TEST` |
| «создай PR во всех репах» | PR в каждом из трёх репозиториев |
| «создай PR в ekaekaz в ветку base» | PR только в `ekaekaz/ekaekaz` с базовой веткой `base` |

## Критерий прохождения

- На неоднозначный запрос Claude задал вопрос и ни одного PR не создал.
- На однозначные запросы PR созданы ровно в тех репозиториях, которые были названы.
